# Product Overview

## Test Modeling App

A visual modeling application for creating test architectures using UML-like class diagram notation. The app allows users to create hierarchical diagrams with elements that can be connected, edited, and organized in a canvas-based interface.

### Key Features

- **Visual Canvas**: Drag-and-drop interface for creating and organizing diagram elements
- **Hierarchical Structure**: Parent-child relationships between elements with automatic layout
- **Multi-platform**: Runs as both a web application and VSCode extension
- **File Operations**: Save/load diagrams as JSON, export as SVG
- **AI Integration**: AI-powered suggestions and generation capabilities
- **Clipboard Support**: Smart paste with automatic hierarchy detection from indented text
- **Keyboard Shortcuts**: Full keyboard navigation and editing support

### Target Users

- Software developers and testers
- System architects
- Anyone needing to visualize hierarchical structures or test architectures

### Deployment

- Web app deployed to GitHub Pages
- VSCode extension for integrated development workflow
- Local development server for testing
